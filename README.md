# Adjoint — AI Development Environment for Unity

Adjoint brings AI-powered development directly into the Unity Editor. Chat with AI, generate 3D models, create audio, write and edit code — all without leaving Unity.

This is a **beta release**. Features and APIs may change between updates.

## Getting Started

1. Open the Adjoint chat window: **Adjoint > Chat** (or `Cmd+Shift+A` / `Ctrl+Shift+A`).
2. Sign in with your Adjoint account.
3. Start chatting — Adjoint can edit scripts, modify scenes, generate assets, and more.

## Requirements

- **Unity 2021.3 LTS or newer** (2021.3 / 2022.3 / 2023.x / Unity 6)
- An Adjoint account — sign up at [adjoint.pro](https://www.adjoint.pro/)

## Features

- **AI Chat** — Conversational AI assistant with full access to your Unity project
- **Code Generation** — Write, edit, and refactor C# scripts
- **3D Model Generation** — Generate 3D models from text descriptions
- **Audio Generation** — Create sound effects and voiceover
- **Scene Editing** — Modify GameObjects, components, and scene hierarchy through chat
- **Agent Architecture** — Multi-step task planning with automatic verification
